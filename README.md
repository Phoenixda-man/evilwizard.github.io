# evilwizard.github.io
Thank you for visiting Evil Wizard.Evil Wizard contains multiple tools for accessing things normally blocked by school filters to avoid kids playing games in class, all of which having creative names, as to avoid being flagged by school filtering tools.
These tools consist of: 
1: A web browser, branded as 'Evil Internet' with the prefix 'ei://' for every site to avoid being blocked by school filters due to having the name of an already blocked site, used for accessing said sites.
2: Various emulators, branded as 'Evil Emus'.
3: Various web games branded as 'Evil HTMLs.
4: A webpage and URL spoofer, branded as 'SiteMask' so that you can help avoid the blocking of this site.
As of now, we only have one Evil Emu, but we plan on adding more in the future. Our only Evil Emu as of now is Evil N64.
